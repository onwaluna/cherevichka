## 🔴 ДЕТАЛЬНЫЙ РАЗБОР ДЕФЕКТОВ ДЛЯ АГЕНТА-РАЗРАБОТЧИКА

### 🔴 [BUG-NEW-001] [P0 BLOCKER] Клик по карточке не открывает досье / на мобиле шторка ломается и уезжает
* **Где воспроизводится:** `app.js` (строка 774), `styles.css` (строки 2555–2572), `index.html` (Spotlight & Directory).
* **Причина:**
  1. На мобильных устройствах `.spot-drawer` позиционируется как `height: 88vh; top: auto; bottom: 0; transform: translateY(100%);`, но при скролле страницы и открытии шторки кнопка `#drawerCloseBtn` и верхняя шапка досье оказываются за границами вьюпорта браузера.
  2. В блоке "Editor's Spotlight" на Главной странице при клике на карточку открывается шторка поверх главной страницы, вместо плавного перехода («проваливания») в подробный каталог к выбранному объекту.
* **Что нужно исправить:**
  - На мобильных устройствах сделать шторку досье нативным bottom-sheet с фиксированной шапкой и кнопкой закрытия, всегда доступной на экране.
  - При клике на карточки спотов в блоке Spotlight на Главной перенаправлять пользователя в раздел каталога с плавным скроллом к выбранному споту и открытием его досье.

### 🔴 [BUG-NEW-002] [P0 BLOCKER] Сайт зависает на белом экране в РФ из-за блокирующих тегов в `<head>`
* **Где воспроизводится:** `index.html` (строки 11–16), `admin.html` (строка 11).
* **Причина:**
  В `<head>` страницы прописаны внешние синхронные стили:
  ```html
  <link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" ...>
  <link href="https://fonts.googleapis.com/css2?family=Bodoni+Moda..." rel="stylesheet">
  ```
  В сетях операторов РФ (МТС, Билайн, Мегафон, Ростелеком) домены `unpkg.com` и `fonts.googleapis.com` замедляются или блокируются ТСПУ. Поскольку это **render-blocking `<link rel="stylesheet">` в шапке**, браузер блокирует показ страницы до таймаута (30–60 секунд белого экрана).
* **Что нужно исправить:**
  1. Скачать `leaflet.css` и `leaflet.js` локально в проект (`assets/vendor/leaflet/`).
  2. Заменить внешние ссылки на локальные файлы: `<link rel="stylesheet" href="assets/vendor/leaflet/leaflet.css">`.
  3. Для шрифтов Google Fonts добавить асинхронную загрузку или системные фолбэки (`font-display: swap;`), чтобы блокировка шрифтов не мешала мгновенному рендерингу сайта.

### 🔴 [BUG-NEW-003] [P0 BLOCKER] Несоответствие картинок на десктопе и мобиле + изолированность Админки
* **Где воспроизводится:** `admin.js` (строка 941), `data/spots.js` (строка 1589), `app.js` (строка 81).
* **Причина:**
  Когда пользователь загружает или меняет обложки в Админ-панели на компьютере, изменения пишутся только в `localStorage` этого конкретного браузера. Когда тот же пользователь открывает сайт со смартфона, телефон открывает исходный `data/spots.js`, где прописаны другие/старые картинки.
* **Что нужно исправить:**
  1. Синхронизировать базовые значения `DESIGN_PANELS` в `data/spots.js` и статическую разметку `index.html`.
  2. В админке при нажатии "Apply Panels" или экспорте явно уведомлять пользователя и обновлять дефолтные ассеты в `data/spots.js`.

### 🔴 [BUG-NEW-004] [P0 BLOCKER] Форма "List Your Brand" ($10) и модалки не адаптированы под мобильные экраны
* **Где воспроизводится:** `styles.css` (строки 1818–1855, 1923), `index.html` (строки 430–502).
* **Причина:**
  В форме `#submitModal` поля сгруппированы в `.form-row-2`:
  ```css
  .form-row-2 {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 1rem;
  }
  ```
  На экранах мобильных телефонов (375px) этот класс заставляет форму делиться на 2 колонки шириной всего по 140px. Тексты накладываются, селекты обрезаются, поля не помещаются в экран.
* **Что нужно исправить:**
  В `@media (max-width: 768px)` добавить:
  ```css
  .form-row-2 {
    grid-template-columns: 1fr;
    gap: 0.8rem;
  }
  .modal-dialog-overlay {
    padding: 0.75rem;
  }
  .modal-content-card {
    max-width: 100%;
    border-radius: 16px;
  }
  .modal-header {
    padding: 1rem 1.1rem;
  }
  .modal-title {
    font-size: 1.35rem;
  }
  .modal-body {
    padding: 1.1rem;
    gap: 1rem;
  }
  ```
